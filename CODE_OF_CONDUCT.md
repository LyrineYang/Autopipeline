# Code of Conduct

This project follows a simple standard: be respectful, specific, and focused on
the work.

## Expected Behavior

- Use clear technical feedback.
- Assume good intent, but ask for evidence when claims affect correctness,
  safety, or performance.
- Keep discussions about benchmarks, hardware, and agent behavior reproducible.
- Respect maintainers' time by providing commands, logs, and environment details.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing secrets, private logs, or exploit details without coordination.
- Repeatedly derailing technical issues after maintainers ask to refocus.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; or block users who
disrupt project work. Security-sensitive issues should be reported through the
security policy instead of public threads.
